## 問題概要
英字は3種類までですが、他の文字には制限がありません。

```python
code = input("jail > ")

if not code.isascii():
    print("Not ascii")
    exit()

if len(set(c for c in code if c.isalpha())) > 3:
    print("Too many alphabets")
    exit()

eval(code)
```
- ASCIIかつ英字は３種類までの入力が可能である。

---

## 試行錯誤
1. evalでOSコマンドが実行可能か調べた。
lsやpwdはOSコマンドであり、Pythonのeval()からそのまま実行できなかった。

2. f と i が合体した「fi」や i と x　が合体した「ⅸ」などを使用して4文字のコマンドを試してみた。
lsやpwdと同様に実行することができなかった。
Pythonにはこれらのシェルコマンドは存在しなく、実行することができないとわかった。

3. Pythonの組み込み関数を調べた
lenやabsなどの関数があったが、3文字の関数は使えそうなものが見つからなかった。

4. 使用可能な英字が3文字ではなく、3種類であることに気づいた。
Pythonの組み込み関数の中に危険そうなexecがあり、この関数は英字3種類であった。
eval文は式のみ実行できるが、execは任意のPython文を実行できるため、import文なども利用できる。
execを使用して考える方針に変更した。

5. exec()の**()**の中を8進数で記述する。
8進数なら16進数とは異なり、数字のみで記述することが可能である。
glob でflag.txtのパスを調べ、catを使用して中身のFlagを取得した。

## まとめ
Pythonにはevalの他にもコマンドを実行できるexecがあり、非常に危険だと理解した。
今回の制約である英字3種類という条件をexec関数を利用し、exec()内を8進数で記述することで英字3種類を条件を満たすことができ、自由にコマンドを実行することができてFlagを取得することができた。
OSコマンドを実行するにはsubprocessモジュールをimportする必要があったので、今回の場合は自身でインポートする必要があった。
