## 問題概要

- シンプルなRSA問題
- 2つの素数の積であるNの値とRSAで暗号化した値が2セット出力される。

```python
e = 65537
p = getPrime(1024)
q1 = getPrime(1024)
q2 = getPrime(1024)

n1 = p * q1
```

## 試行錯誤
1. RSAの解読を調べて、公式通りにデコードしてみる。
RSAは秘密鍵dを求めるために素数pとqから*(p-1)`*`(q-1)*で f を求める。
その後 ** e ^ -1 mod f **で d を求める。 
最後に** c ^ d mod n **(n= p `*` q)でデコードができる。
今回の場合は p と q がわからないので、二つのnの値、n1とn2からpを計算する必要がある。

```
f = (p-1)*(q-1)
d = pow(e, -1 , f)
m =pow(c, d, n)
```

2. 共通素因数pを求める。
今回はp、q1、q2が素数であり、getprime()で生成される。
その積であるn1とn2の値のみがわかっているが、pとqはわからない。

```
n1 = p * q1
n2 = p * q2
```
しかし、pは共通であり、n1、n2の両方で用いられていることがわかる。
そして、q1とq2は異なる素数である。
ということは、n1とn2は素因数にpを持っていることがわかり、n1とn2の最大公約数がpになっている。
math.gcd(n1、n2)で最大公約数であるpが求まり、pがわかるとqも求まる。
1で使用した公式に当てはめるとflagが手に入った。

```
p = math.gcd(n1, n2)
q1 = n1 // p
q2 = n2 // p
```
## まとめ
- n1とn2の最大公約数を求めることで、共通素因数であるpを特定できた。
- 素数がわかるとあとはRSAの解読の方法に従うだけでデコードが可能である。
- getPrime() が素数を生成する関数であることを見落としており、共通因数の存在に気付くまで時間がかかった。
