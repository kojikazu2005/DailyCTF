学なび・気づき
- lazy‑RSA は「秘密の素数 p, q に線形の関係を与えてしまう」ことで RSA が破られる問題。
- RSA の安全性は「p, q が完全に秘密であること」に依存していることを再確認。
- SymPy を使うと、数学的な問題はコード量が大幅に減る。
 → Crypto の中でも「式変形が面倒な問題」は SymPy が強い。
- Python の pow(e, -1, phi) は逆元計算として最速で安全。
 → 拡張ユークリッド法を自作する必要がない。
- RSA の復号pow(c, d, n) 



試行錯誤ログ
- 最初は p, q をどう求めるかが分からず、普通の RSA のように因数分解を考えたが、当然無理。
- 問題文に a, b, hint があることに気づき、「これは連立方程式で p, q を求めるタイプだ」と判断。
連立方程式
p*q = n
ap + bq = hintを見て、手計算で二次方程式に変形しようとしたが、式変形が面倒だった。
そこで SymPy を使うことを決めた。
→ 記号計算で p, q を直接求められるので実装が短くなる。
SymPy の solve は複数解を返すため、
「正の整数で、かつ n を割り切るもの」を選ぶ必要があった。
p, q が求まった後は、通常の RSA と同じ流れで復号できた。
