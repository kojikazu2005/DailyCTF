# 使用モジュールまとめ（lazy-rsa）

この問題で使用した Python のモジュール・関数・ライブラリをまとめる。

---

## Python 組み込み関数

### pow
- `pow(e, -1, phi)`  
  → RSA の逆元計算に使用  
- `pow(c, d, n)`  
  → RSA の復号処理に使用  

Python の pow は高速なモジュラー演算を内部で行うため、
自作の modexp より安全で高速。

---

## SymPy（記号計算ライブラリ）

使用した関数：
- `symbols`
- `Eq`
- `solve`

役割：
- RSA の p, q を数学的に導出するために使用  
- 連立方程式  
  - p*q = n  
  - a*p + b*q = hint  
  を記号計算で解いた  

SymPy を使うことで、数学的に正確な解を得られ、
実装が短くなり、バグが減る。

---



- `long_to_bytes`  
  → RSA の復号結果（整数）を文字列に変換するために使用
